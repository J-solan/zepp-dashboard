# frontend

React + TypeScript + Vite + Tailwind. Consume la API de `backend/`.

```bash
npm install
npm run dev     # http://localhost:5173, con proxy /api -> localhost:8000
npm test        # vitest
npm run lint    # oxlint
npm run build   # -> dist/, que uvicorn sirve directamente
```
